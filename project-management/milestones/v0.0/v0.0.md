# v0.0 — 最小のdense検索を実行できる

## 目標

少量の固定Markdown文書を取り込み、固定ルールでチャンク化し、Embeddingを保存する。Haskell CLIから質問を入力し、質問に近い文書断片をexact vector searchで取得して表示できる、最小のdense検索経路をローカル環境で動作させる。

## 対象範囲

- 少量の固定Markdown文書の読み込み
- Haskellによる固定ルールでのチャンク分割
- Python AI Serviceによる文書チャンクと質問のEmbedding生成
- PostgreSQL / pgvectorへの文書チャンクとEmbeddingの保存
- Haskell CLIからの質問入力
- pgvectorを使用したexact vector search
- 検索結果となる上位チャンクのCLI表示
- ローカル環境での文書取り込みから検索結果表示までの一連の実行

## 対象外

- TXT、PDF、画像など、固定Markdown以外の文書形式への対応
- 文書、文書集合、チャンク条件、Embedding条件のバージョン管理
- 正規化規則、offset、EvidenceSpanによる元文書への厳密な追跡
- 評価データ、検索指標、実験結果の保存・比較、Markdown / CSVレポート
- PostgreSQL全文検索、hybrid検索、reranking
- 回答生成、構造化引用、no-answer判定
- HNSW / IVFFlatなどの近似検索index
- AWSへの配置
- 本格的なWeb UI、認証、ストリーミング、非同期job

## 成功条件

- [ ] 固定Markdown文書をHaskellから読み込み、本文を後続処理へ渡せる
- [ ] 読み込んだ文書を固定ルールでチャンク化できる
- [ ] Python AI Serviceで文書チャンクのEmbeddingを生成できる
- [ ] 文書チャンクとEmbeddingをPostgreSQL / pgvectorへ保存できる
- [ ] Haskell CLIから質問を入力し、質問のEmbeddingを生成できる
- [ ] pgvectorのexact vector searchで質問に近い上位チャンクを取得できる
- [ ] 取得した上位チャンクをHaskell CLIへ表示できる
- [ ] 文書取り込みから検索結果表示までを、定めた手順でローカル環境から再実行できる
