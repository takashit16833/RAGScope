# RS-0001 — [Feature] 固定Markdown文書をHaskellで読み込む

> [!summary] このTicketで可能にすること
> リポジトリ内に用意した1件の固定Markdown文書をHaskellからUTF-8テキストとして読み込み、内容を確認できるようにする。

## コンテキスト

- Milestone: [[v0.0]]
- Epic: [[v0.0-document-ingestion]]
- 設計書: [[ragscope-design#12. v0.0 実装内容]]
- 対象コンポーネント: Haskell CLI / 文書読み込み処理

## 目的

v0.0の最初の処理である「固定文書を入力として扱う」ための最小経路を作る。  
このTicketでは、後続のchunk分割やEmbedding生成へ進む前に、HaskellがMarkdown本文を確実に取得できることだけを確認する。

## 完了条件

- [ ] リポジトリ内の固定Markdown文書1件をHaskellから読み込める
- [ ] 読み込んだ内容を標準出力またはテストで確認できる
- [ ] 日本語またはASCII以外を含むUTF-8本文を文字化けせず扱える
- [ ] ファイルが存在しない場合に、原因を判断できるエラーになる
- [ ] 実行手順と実際の結果を本ノートへ記録した

## 対象外

- 複数文書の一括読み込み
- ディレクトリ走査
- LF・NFCの正式な正規化
- Markdown構文解析
- chunk分割
- Embedding生成
- PostgreSQLへの保存
- CLIオプションや設定ファイルの一般化

## 実装方針の仮置き

> [!warning] 確定設計ではない
> 次は最初の実装を始めるための最小案であり、実装結果に応じて変更してよい。

1. リポジトリ内に小さな固定Markdown文書を1件置く。
2. Haskellから固定パスまたは最小限の引数でファイルを読む。
3. 読み込んだ本文を`Text`として保持する。
4. 標準出力またはテストで本文を確認する。
5. 存在しないパスを指定した場合のエラーを確認する。

### 手順

1. 固定Markdown文書を用意する。
2. Haskellの実行コマンドを実行する。
3. 出力された本文を元ファイルと比較する。

### 期待結果

- 固定Markdown文書の本文が文字化けせず取得できる。
- 読み込み失敗時に、成功したように処理を継続しない。
- エラーの原因がファイル読み込みであると判断できる。
