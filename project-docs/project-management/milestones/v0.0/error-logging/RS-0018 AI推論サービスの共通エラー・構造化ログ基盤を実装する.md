# RS-0018 AI推論サービスの共通エラー・構造化ログ基盤を実装する

## 目的

AI推論サービスへ、当時の共通エラー・構造化ログ契約に従うPythonの最小基盤を実装する計画として作成したTicketである。

## 中止理由

[RS-0023](<./RS-0023 OpenTelemetry Logsを前提に実行追跡・構造化ログアーキテクチャを再設計する.md>)でObservability全体を再設計した結果、このTicketが前提としていた共通`RAGScopeError`、`LogEvent` / `EventContext` / `EventSpec`、RAGScope独自のLogging Runtime / Sink、共有ログJSON Schema、`execution_id`による共通実行追跡を現在設計として採用しないことを決定した。

AI推論サービスは、旧契約を実装してから移行するのではなく、[ADR-0006](<../../../../adr/ADR-0006 OpenTelemetryをObservabilityの共通基盤とし、Trace・Logs・Metricsの責務を分ける.md>)と[Observability設計](../../../../design/observability/README.md)に従って最初からOpenTelemetryの最小基盤を実装する。

後続作業は[RS-0025 AI推論サービスへOpenTelemetry Observability最小基盤を実装する](<./RS-0025 AI推論サービスへOpenTelemetry Observability最小基盤を実装する.md>)が担当する。

## 結果

- 本Ticketは実装へ着手せず中止した。
- 旧共通エラー・構造化ログ契約をAI推論サービスへ実装しない。
- 後続はRS-0025へ引き継いだ。
