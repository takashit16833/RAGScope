# 文書

このディレクトリは、[RAGScopeドメインモデル](../../RAGScopeドメインモデル.md)で定義する「文書」ドメインの機能設計の入口・索引である。

「文書」ドメイン自体の責務は[RAGScopeドメインモデル](../../RAGScopeドメインモデル.md)を正本とし、このREADMEでは配下の機能設計を読み分けるための情報だけを扱う。

> [!warning] 設計準備中
> 次の4文書は、後続の設計作業を進めるための現在の仮置きである。この分割自体を`documents`ドメインの正式な機能分類として固定しない。各設計を具体化するときに、責務に応じて分割・統合・改名・削除してよい。

| 文書 | 現時点で扱う予定の範囲 |
|---|---|
| [文書取り込み設計](./文書取り込み設計.md) | 技術文書をRAGScopeへ取り込む処理 |
| [文書・版管理設計](<./文書・版管理設計.md>) | 文書集合、文書、文書バージョンなどの管理 |
| [文書分割設計](./文書分割設計.md) | 文書バージョンを文書チャンクへ分割する処理 |
| [検索用データ準備設計](./検索用データ準備設計.md) | 文書チャンクから検索に必要なデータを準備する処理 |
