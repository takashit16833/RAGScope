# 検索用データ準備設計

文書チャンクから、検索に必要なデータを準備する処理を扱う。

## 機能オーバービュー

```mermaid
flowchart LR
    Chunk["文書チャンク"]
    Prepare["検索用データ準備"]
    SearchData["検索用データ<br/>Embeddingなど"]

    Chunk --> Prepare --> SearchData
```

文書チャンクのEmbeddingを含む検索用データの生成と保持を具体化する。質問Embeddingの生成や、準備したデータを使った検索そのものは「検索・回答生成」ドメインで扱う。
