# 検索用データ準備設計

文書チャンクから、検索に必要なデータを生成・保持する処理を扱う。

## 処理概要

```mermaid
flowchart LR
    Chunk["文書チャンク"]
    Prepare["検索用データ準備"]
    SearchData["検索用データ"]
    Embedding["文書チャンクのEmbedding"]

    Chunk --> Prepare
    Prepare --> SearchData
    SearchData -->|"含む"| Embedding
```

検索用データは、どの文書チャンクから生成されたかを追跡できる状態で保持する。文書チャンクのEmbeddingは検索用データの1つであり、Embedding生成ではAI推論サービスを利用する。

質問Embeddingの生成や、準備した検索用データを使って文書チャンクを検索する処理は「検索・回答生成」ドメインで扱う。
