# 文書・版管理設計

文書集合、文書、文書バージョンを識別し、異なる文書や版を混同せず管理するための設計を扱う。

## 管理対象の関係

```mermaid
flowchart LR
    Collection["文書集合"] -->|まとめて扱う| Document["文書"]
    Document -->|内容の版| Version["文書バージョン"]
```

この設計では、文書集合・文書・文書バージョンの関係、各対象の識別、保存、取得、更新時の扱いを定義する。

文書の具体的な内容は文書バージョンとして区別する。文書バージョンから文書チャンクを生成する処理は[文書分割設計](./文書分割設計.md)で扱う。
