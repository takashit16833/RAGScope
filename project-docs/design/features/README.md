# 機能設計

RAGScopeの個別機能について、処理規則、入出力、具体的にどのような失敗があるか、他機能への受け渡しを定義する設計書の索引である。

ユースケース全体で何を成功・最終失敗とみなすかは[ユースケース基本設計](../ユースケース基本設計.md)、各機能で定義した失敗をHaskell上でどう表現しユースケース境界から受け渡すかは[ユースケース詳細設計](../ユースケース詳細設計.md)を正本とする。
