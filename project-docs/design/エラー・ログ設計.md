# エラー・ログ設計

> [!abstract] この文書の役割
> 旧`エラー・ログ設計.md`を参照している文書から、分割後の現在設計へ移動するための入口である。
>
> 共通エラーと構造化ログの現在設計は、この文書では定義しない。

## 現在設計の正本

| 確認したいこと | 正本 |
|---|---|
| 失敗をどう表現し、公開情報と内部原因をどう分けるか | [エラー設計](./エラー設計.md) |
| 処理中の出来事をどう関連付け、JSONとして出力するか | [構造化ログ設計](./構造化ログ設計.md) |
| 具体的な処理種別、開始・成功・失敗の観測点、イベント固有情報 | 各機能設計。文書処理については[文書処理設計](./文書処理設計.md) |

## エラーと構造化ログの関係

共通エラーは失敗の意味を保持する値であり、自分ではログを出力しない。

各機能設計で定義した処理結果の確定境界が、失敗を表すログイベントを1回だけ記録する。その際は、共通エラーのうち記録を許可した情報だけを`LogEvent.error`へ渡し、内部原因や元の例外メッセージは記録しない。
