# 設計書テンプレートの選択

> [!abstract] この文書の役割
> 機能別設計書を新規作成するときに、設計対象の性質に合うテンプレートを選ぶための入口である。

| テンプレート | 中心となる問い | 主な対象 |
|---|---|---|
| [処理・振る舞い設計書テンプレート](./処理・振る舞い設計書テンプレート.md) | 何が、どの順序で、どの条件に従って処理されるか | 入出力、処理段階、分岐、状態変化、後続処理への受け渡し |
| [構造・契約設計書テンプレート](./構造・契約設計書テンプレート.md) | 何を共有し、それぞれが何を意味し、どの規則を守るか | 項目、語彙、識別子、形式、公開範囲、不変条件 |

## 選択方法

1. 読者が最初に答えを得たい問いを確認する。
2. 主となる性質に対応するテンプレートを1つ選ぶ。
3. もう一方の性質も必要な場合は、必要な節だけを追加する。
4. 2つのテンプレートを単純に結合し、すべての章を持つ文書にしない。

> [!important] テンプレートは帳票ではない
> 設計対象に不要な見出しは削除する。どちらにも自然に適合しない設計を無理に押し込まず、文書の分割または設計対象の再定義を検討する。

`システムアーキテクチャ.md`はシステム全体を扱う特別な文書であり、いずれかの機能別設計テンプレートへ機械的に合わせない。

選択基準と運用規則の正本は、[RAGScope文書管理規約「4.5 機能設計の種類と構成」](<../rules/RAGScope文書管理規約.md#4.5 機能設計の種類と構成>)とする。
